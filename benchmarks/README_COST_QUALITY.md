# Cost / Quality Regression Benchmark

The fixed fixture `quality_regression_v01.json` covers casual, definition, compact analysis,
standard comparison, and explicit deep reasoning.

CI/unit tests validate deterministic detail/budget/promotion behavior. Production-quality
evaluation should additionally record route, model, answer length, actual token usage,
latency, guard result, and human quality outcome. The target Sol share is 10–20%; this is
an evaluation target, not a quota that overrides task quality.
